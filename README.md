# Lighture Drinks

Situs pemesanan minuman Lighture Drinks - menu, keranjang, pembayaran QRIS/tunai, dan panel admin.

Data pesanan, stok, dan laporan disimpan di Firebase Firestore (lihat konfigurasi di dalam `index.html`).

## Hosting
Situs ini didesain untuk dijalankan sebagai file statis (mis. GitHub Pages). Buka `index.html` di server statis mana pun.
